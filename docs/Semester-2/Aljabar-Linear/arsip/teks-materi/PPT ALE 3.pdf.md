## Halaman 12

Hukum Perkalian Matriks :
➢Hukum Distributif, A*(B+C) = AB + AC
➢Hukum Assosiatif, A*(B*C) = (A*B)*C
➢Tidak Komutatif, A*B B*A
➢Jika A*B = 0, maka beberapa kemungkinan
➢(i)   A=0 dan B=0
➢(ii)  A=0 atau B=0
➢(iii) A0 dan B0
➢Bila A*B = A*C, belum tentu B = C
