• Komutatif →a + b = b + a
• Asosiatif →(a+b)+c = a+(b+c)
• Elemen identitas terhadap penjumlahan
• Sifat tertutup-> hasil penjumlahan vektor juga berupa vektor 
• Ketidaksamaan segitiga |u+v| ≤ |u| + |v|

• 0u = 0, m0 = 0.
• Jika mu = 0, maka m=0 atau u = 0
