# RPS — Aljabar Linear

- Mahasiswa mampu menjelaskan dan menyelesaikan soal terkait vector dan matriks

- Mahasiswa mampu memberikan contoh system persamaan linear dan penerapanya dalam ilmu computer

- Mahasiswa mampu memberikan contoh transformasi vector linear untuk mendukung pemodelan dan analisa masalah

- Mahasiswa mampu menjelaskan bagaimana penggunaan konsep dan teori aljabar linear dalam mendukung pemecahan masalah dalam disiplin ilmu computer
