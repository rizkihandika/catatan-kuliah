## Konsep kunci

### 1. Apa itu pemrograman visual
- **Intuisi**: menyusun aplikasi seperti menata perabot — taruh tombol, kotak teks, label di jendela (form) dengan drag & drop, lalu tulis kode untuk reaksi tiap elemen.
- Pemrograman **visual** = antarmuka (GUI) dibangun secara visual di desainer, bukan diketik baris demi baris.
- Model eksekusinya **event-driven**: program menunggu kejadian (klik, ketik, form dibuka) lalu menjalankan kode yang terikat ke kejadian itu.
