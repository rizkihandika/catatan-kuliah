- **[03:11–05:13] Karakteristik algoritma.** Fondasi penting bagi developer/programmer. Urutan langkah demi langkah untuk menyelesaikan masalah; langkahnya **terbatas** (*finite*, supaya tepat sasaran), **diskret/tidak ambigu**, ada **data input** untuk menghasilkan **data output**, tiap instruksi dapat dilakukan dalam waktu terbatas, dan **deterministik**. Contoh masalah: dapatkan tiket/rute dari Vancouver ke Ottawa besok pagi, alokasikan tenaga kerja untuk memaksimalkan keuntungan, membuat mie instan, mengikat tali sepatu anak usia 5 tahun.
- **[05:13–06:14] Batasan komputer.** Masalah pengolahan data diterjemahkan menjadi program; komputer hanya dapat **input, simpan (store), proses, output** data, sehingga instruksi algoritma terbatas pada keempat fungsi itu.
- **[06:14–08:18] Representasi algoritmik (keyword).** Input: `get` (mendapatkan data dari user). Storage: `given` (data masukan yang diketahui), `result` (hasil), `intermediate` (variabel sementara/temporary), `set` (menetapkan nilai langsung). Proses: `let` (assignment/perhitungan aritmetika), `loop` (perulangan), `if` (percabangan/kondisional). Output: `give`. Model IPO: data/masalah sebagai input, diproses dengan algoritma menjadi output/solusi.
- **[08:18–10:27] Deskripsi algoritma.** Identifikasi dan beri nama setiap input (`given`, seperti "diketahui" di soal matematika), identifikasi dan beri nama hasil (`result`), beri nama algoritma, lalu gabungkan menjadi **definition**: `result = name(given...)`.
- **[10:27–11:30] Metode (method).** Rangkaian instruksi terbatas yang melakukan komputasi dari given menuju result. Contoh assignment: `x = 5y + 16`; kiri tanda sama dengan adalah nama variabel, kanan adalah nilai/ekspresi. Variabel = lokasi unik di memori komputer yang berisi nilai.
- **[11:30–16:39] Interpretasi assignment dan beda matematika vs ilmu komputer.** Assignment dijalankan dua langkah: (1) evaluasi ekspresi di sisi kanan, (2) simpan hasilnya ke sel memori variabel di kiri. Contoh `let side_size = 15`, `let area = side_size * side_size`. Perbedaan: dalam matematika A = B berarti B = A, tetapi `let A = B` berbeda dengan `let B = A`. Relasi B = A + 1 pada matematika selalu benar; pada komputer hanya benar setelah instruksi `B = A + 1` dan sebelum A diubah (contoh A = 5 lalu B = 6, lalu A = 2 membuat relasi tidak lagi benar). `let A = A + 3` bermakna nilai A baru = A lama + 3 (valid di komputer, tidak di matematika). `A + 5 = 3` hanya valid di matematika; di komputer sisi kiri harus nama variabel.
- **[16:39–17:40] Perintah input/output.** `get variable` (variabel berasal dari given; user memasukkan nilai, mis. `get side_size`); `give variable` (menampilkan nilai variabel hasil, mis. `give area`).
- **[17:40–24:50] Contoh algoritma.**
  1. `Sum3`: given n1, n2, n3; result total; `get` ketiganya, `let total = n1 + n2 + n3`, `give total`.
  2. `Division`: given x, y; result quotient; `get x`, `get y`, `let quotient = x / y`, `give quotient`.
  3. Jumlah dan hasil kali dua bilangan (`SumProduct`): given n1, n2; result total dan product; `let total = n1 + n2`, `let product = n1 * n2`, `give total`, `give product`.
  4. `Average3`: given n1, n2, n3; result sum dan average; `let sum = n1 + n2 + n3`, `let average = sum / 3`, `give sum`, `give average`.
- **[24:50–26:54] Intermediate dan algoritma 5 (swap).** Intermediate = variabel perantara untuk nilai sementara. `Swap(x, y)`: given x, y; result x, y; intermediate `temp`. Langkah: `get x`, `get y`, `let temp = x`, `let x = y`, `let y = temp`, `give x`, `give y`; nilai x dan y tertukar.
- **[26:54–27:54] Algoritma 6 (`Add xy`).** Menambah x dan y dan menyimpan hasil di x; result x, intermediate tidak ada (none). `get x`, `get y`, `let x = x + y`, `give x`. Contoh x = 2 dan y = 5 menghasilkan x = 7.
- **[27:54–29:56] Ringkasan komponen.** **Name**: nama formal algoritma (wajib, mencerminkan prosesnya). **Given**: nilai/input yang diberikan. **Result**: nama nilai hasil/solusi. **Intermediate**: variabel perantara. **Definition**: definisi formal dengan format name, given, result. **Method**: langkah demi langkah menyelesaikan masalah.
- **[28:55–33:01] Penelusuran (trace) algoritma.** Tujuan: memastikan algoritma benar sebelum coding (tes paling dasar). Langkah: beri nomor tiap instruksi; buat tabel (kolom: nomor baris, instruksi/method, lalu satu kolom per variabel: given, result, intermediate); jalankan dari baris pertama dan catat perubahan nilai variabel setelah tiap instruksi, kolom lain dibiarkan kosong. Contoh: trace algoritma 4 dengan input 24, 31, 35 (sum 90, average 30); trace algoritma 5 (swap) dengan x = 25 dan y = 88.
- **[33:01–35:05] Evaluasi mandiri.** (1) Tulis algoritma penjumlahan 5 bilangan lalu trace dengan 1, 3, 5, 7, 9; (2) algoritma rata-rata 5 bilangan (1, 3, 5, 7, 9); (3) algoritma perkalian 3 bilangan dengan input 2, 9, 6, lalu trace.

**Poin penting untuk ujian:**
- Karakteristik algoritma: terbatas (*finite*), tidak ambigu, ada input dan output, deterministik, tiap instruksi selesai dalam waktu terbatas.
- Komputer hanya input, simpan, proses, output; model IPO.
- Keyword: `get` (input), `let` (assignment), `loop`, `if`, `give` (output); komponen name, given, result, intermediate, definition, method.
- `=` pada assignment: kiri harus nama variabel, kanan ekspresi dievaluasi dulu; `let A = B` tidak sama dengan `let B = A`; `let A = A + 3` valid.
- Algoritma swap memakai variabel intermediate `temp`.
- Cara trace algoritma dengan tabel (satu kolom per variabel, nilai berubah per instruksi).

**Info dari dosen:** Ada evaluasi mandiri (tiga latihan: jumlah 5 bilangan, rata-rata 5 bilangan, perkalian 3 bilangan beserta trace) yang disebut "wajib" untuk pemahaman; tidak ada tenggat yang disebut. Referensi bahan ajar ditampilkan di akhir video.
