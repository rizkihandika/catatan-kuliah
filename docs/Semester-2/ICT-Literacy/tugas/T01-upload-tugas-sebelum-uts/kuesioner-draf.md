# Draf Instrumen Kuesioner — ICT Literacy × Pemanfaatan AI Generatif

> **Status: DRAF dari Claude (2026-11-27), untuk kamu sesuaikan.** Ubah kalimat butir dengan gayamu, buang/tambah butir, lalu uji coba ke ± 5 teman sebelum disebar (Des 2026). Kisi-kisi (tabel indikator) boleh masuk Bab 3.4; **butir lengkapnya taruh di lampiran**, bukan di badan Bab 3.

## Untuk Bab 3 (yang perlu kamu tulis dengan bahasamu)
- **Variabel X**: tingkat ICT literacy, 5 komponen ICT Literacy Panel (2002): *access, manage, integrate, evaluate, create*.
- **Variabel Y**: pemanfaatan AI generatif secara kritis dan etis. Indikatornya disusun dari Miao & Holmes (2023, UNESCO), Kusumawardani dkk. (2024, panduan Diktiristek), dan Long & Magerko (2020).
- **Skala**: Likert 1–5 (1 = Sangat Tidak Setuju … 5 = Sangat Setuju). Butir bertanda **(R)** dinilai terbalik (skor 6 − jawaban) saat analisis.
- **Kategori skor rata-rata** (interval sama, (5 − 1)/5 = 0,8): 1,00–1,80 sangat rendah · 1,81–2,60 rendah · 2,61–3,40 sedang · 3,41–4,20 tinggi · 4,21–5,00 sangat tinggi.
- **Uji instrumen** (sebut di Bab 3, dikerjakan nanti): validitas (korelasi item-total, r hitung > r tabel) dan reliabilitas (Cronbach's alpha ≥ 0,60/0,70). Bisa dihitung di Excel/SPSS/JASP.
- **Analisis**: statistik deskriptif (persentase, mean per indikator) untuk RM 1–2; korelasi (Pearson, atau Spearman bila data tidak normal) untuk RM 3.

## Bagian A — Persetujuan & profil (wajib, anonim)
1. Persetujuan: "Saya bersedia mengisi secara sukarela, data dipakai hanya untuk tugas kuliah dan dilaporkan tanpa identitas." (Ya / Tidak → selesai)
2. Usia: < 17 (→ selesai) · 17–20 · 21–25 · 26–30 · 31–35 · > 35 (→ selesai)
3. Jenis kelamin: L / P / tidak ingin menyebutkan
4. Status utama: pelajar · mahasiswa · bekerja · bekerja sambil kuliah · lainnya
5. Pendidikan terakhir: SMA/sederajat · D3 · S1 · S2+
6. Pernah memakai AI generatif berbasis teks (ChatGPT, Gemini, Claude, Copilot, Meta AI, dll.)? Ya / Tidak (→ selesai)
7. AI yang dipakai (boleh lebih dari satu): ChatGPT · Gemini · Claude · Copilot · Meta AI · Perplexity · DeepSeek · lainnya
8. Frekuensi: < 1×/minggu · 1–3×/minggu · 4–6×/minggu · setiap hari
9. Tujuan utama (boleh lebih dari satu): belajar/tugas · pekerjaan · hiburan/game · mencari informasi · menulis/konten · pemrograman · lainnya
10. Sudah berapa lama memakai AI generatif: < 6 bln · 6–12 bln · 1–2 th · > 2 th

> Butir 8–10 menjawab **RM 2 (pola pemanfaatan)**. Kategori tujuan disejajarkan dengan APJII (2026) supaya bisa dibandingkan di Bab 4.

## Bagian B — Variabel X: ICT Literacy (15 butir)
| Komponen | No | Pernyataan |
|---|---|---|
| **Access** (menemukan & mengambil informasi) | X1 | Saya mampu menemukan informasi yang saya butuhkan di internet dengan cepat. |
| | X2 | Saya terbiasa memakai kata kunci atau filter pencarian yang spesifik. |
| | X3 | Saya tahu sumber mana yang tepat untuk jenis informasi tertentu (mis. jurnal, situs resmi, berita). |
| **Manage** (mengelola informasi) | X4 | Saya menyimpan dan mengelompokkan file/informasi digital secara teratur. |
| | X5 | Saya mencatat sumber informasi yang saya pakai. |
| | X6 | Saya kesulitan menemukan kembali informasi yang pernah saya simpan. **(R)** |
| **Integrate** (menggabungkan & meringkas) | X7 | Saya mampu meringkas informasi dari beberapa sumber dengan kata-kata sendiri. |
| | X8 | Saya bisa membandingkan informasi dari sumber yang berbeda tentang topik yang sama. |
| | X9 | Saya mampu menghubungkan informasi baru dengan pengetahuan yang sudah saya miliki. |
| **Evaluate** (menilai kualitas informasi) | X10 | Saya memeriksa siapa penulis atau pembuat sebuah informasi sebelum mempercayainya. |
| | X11 | Saya bisa membedakan informasi fakta dan opini/hoaks. |
| | X12 | Saya langsung membagikan informasi yang menarik tanpa memeriksanya dulu. **(R)** |
| **Create** (menghasilkan karya digital) | X13 | Saya mampu membuat dokumen, presentasi, atau konten digital yang rapi. |
| | X14 | Saya bisa menyajikan informasi dalam bentuk yang mudah dipahami orang lain (tabel, grafik, infografis). |
| | X15 | Saya menghargai hak cipta saat memakai karya orang lain dalam konten saya. |

## Bagian C — Variabel Y: Pemanfaatan AI generatif secara kritis & etis (15 butir)
| Indikator | No | Pernyataan |
|---|---|---|
| **Pemahaman cara kerja & batasan AI** | Y1 | Saya memahami bahwa AI generatif menyusun jawaban dari pola data, bukan "mengetahui" kebenaran. |
| | Y2 | Saya tahu AI bisa memberikan jawaban yang terdengar meyakinkan tetapi salah (halusinasi). |
| | Y3 | Saya tahu informasi dari AI bisa sudah usang atau tidak lengkap. |
| **Verifikasi hasil (kritis)** | Y4 | Saya memeriksa ulang fakta/angka dari AI ke sumber lain sebelum memakainya. |
| | Y5 | Saya mengecek apakah referensi/sumber yang disebut AI benar-benar ada. |
| | Y6 | Saya langsung memakai jawaban AI tanpa memeriksanya. **(R)** |
| **Pemakaian bertujuan & mandiri** | Y7 | Saya memakai AI untuk membantu memahami materi, bukan menggantikan proses berpikir saya. |
| | Y8 | Saya tetap mampu mengerjakan tugas/pekerjaan tanpa bantuan AI. |
| | Y9 | Saya merasa tidak bisa menyelesaikan tugas tanpa AI. **(R)** |
| **Integritas & kejujuran** | Y10 | Saya menyebutkan (mengakui) bila sebagian karya saya dibantu AI, sesuai aturan yang berlaku. |
| | Y11 | Saya pernah mengumpulkan hasil AI sebagai karya sendiri tanpa diubah. **(R)** |
| | Y12 | Saya mengikuti aturan dosen/tempat kerja tentang boleh tidaknya memakai AI. |
| **Privasi & tanggung jawab** | Y13 | Saya tidak memasukkan data pribadi atau data rahasia (milik saya/orang lain) ke AI. |
| | Y14 | Saya sadar hasil AI bisa mengandung bias atau stereotip. |
| | Y15 | Saya tidak memakai AI untuk membuat konten yang menipu atau merugikan orang lain (mis. hoaks, deepfake). |

## Bagian D — Pertanyaan terbuka (opsional, data kualitatif pendukung)
1. Ceritakan satu pengalaman saat AI memberikan jawaban yang salah. Bagaimana Anda mengetahuinya?
2. Menurut Anda, apa batas wajar memakai AI untuk belajar atau bekerja?
