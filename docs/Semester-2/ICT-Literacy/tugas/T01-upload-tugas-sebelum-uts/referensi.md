**Cara pakai:**
- ⭐ = prioritas untuk Tugas 1. Ada **15 sumber ⭐** (13 jurnal/buku + APJII + Sugiyono), cukup untuk syarat ≥ 10.

Semuanya ada di referensi-zotero.ris *(file kerja pribadi — tidak dipublikasikan)*: di Zotero pilih **File → Import… → A file → referensi-zotero.ris**, lalu lampirkan PDF-nya.
