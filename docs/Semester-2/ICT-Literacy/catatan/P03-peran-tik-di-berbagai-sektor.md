# P03 — Penerapan TIK di Berbagai Sektor

Tanggal: 2026-11-04 · Sumber: [`Modul ICT Literacy_03_Penerapan TIK di Berbagai Sektor.pdf`](../materi/Modul%20ICT%20Literacy_03_Penerapan%20TIK%20di%20Berbagai%20Sektor.pdf), [`Analisis ICT di berbagai Sektor.pdf`](../materi/Analisis%20ICT%20di%20berbagai%20Sektor.pdf), video "Sesi III ICT literasi" (Bu Fesa, ±25 menit), video interaktif "ICT for Education"

## Ringkasan 3 kalimat
Pengguna TIK tersusun dalam **piramida**: dari puncak (sedikit, paling ahli) **ICT Creators → Spreaders → Enablers → Helpers → Users** (terbanyak). TIK dipakai untuk memecahkan masalah masyarakat di banyak sektor, dengan **telekomunikasi sebagai tulang punggung**, lalu pendidikan, sektor publik, kesehatan, dan pertanian. Literasi TIK diperlukan agar teknologi dipakai **efektif, aman, dan bertanggung jawab**.

## Konsep kunci

### 1. Piramida pengguna TIK
| Kelompok (puncak → dasar) | Peran |
|---------------------------|-------|
| **ICT Creators** | inovator: executive management, research, development, testing & QA, requirements & specifications |
| **ICT Spreaders** | penyebar: marketing & sales, sales support engineering |
| **ICT Enablers** | operasional: IT management, system architecture/integration, solution maintenance, installation & provisioning |
| **ICT Helpers** | penolong: solution support, user support, training |
| **ICT Users** | terbanyak: business users & consumer users |

Catatan: modul/video menyebut "3 tingkatan", tetapi menjelaskan **5 kelompok**. Creator tidak hanya di industri TI (juga bisnis, kesehatan, pendidikan).

### 2. TIK untuk memecahkan masalah masyarakat
- Daya saing: **IMD World Competitiveness Ranking 2023 — Indonesia peringkat 34 dari 64** (2022: 44); 4 pilar: kinerja ekonomi, efisiensi pemerintah, efisiensi bisnis, infrastruktur.
- **Benchmark Jepang**: TIK untuk aging society, kesehatan, administrasi, pendidikan, lingkungan & energi → sistem terintegrasi.
- **Literasi budaya**: faktor budaya (agama, etnis, tradisi) memengaruhi cara memakai TIK.
- **Literasi media**: akses → memahami → memakai media untuk berekspresi.

### 3. Lima sektor utama (modul & video)
| Sektor | Peran TIK |
|--------|-----------|
| **Telekomunikasi** | **tulang punggung** TIK: info cuaca untuk petani/nelayan, sekolah terpencil terhubung, transaksi online dengan pemerintah |
| **Pendidikan** | sumber belajar untuk daerah terpencil, perpustakaan digital, manajemen akademik berbasis cloud, **PJJ/kelas virtual** |
| **Sektor publik** | 3 manfaat: **pelayanan efisien, perencanaan kebijakan, transparansi**; e-government, e-procurement, EDI, data warehouse, intranet |
| **Kesehatan** | **rekam medis elektronik**, efisiensi biaya RS, **telemedicine** |
| **Pertanian** | info tepat waktu → keputusan tani lebih baik, akses pasar online, jembatan riset–petani, akses modal |

Sektor tambahan (infografis tugas): bisnis (e-commerce, pembayaran digital), industri (smart factory, IoT), transportasi (GPS, ojek online), komunikasi (email, video conference), lingkungan (pemantauan kualitas).

### 4. ICT for Education (video interaktif, 7 manfaat)
interactive learning · akses informasi · collaboration tools · personalized learning · efisiensi waktu · koneksi global · pengembangan skill.

## Sering keluar di ujian / mudah keliru
- Urutan piramida dari **puncak**: Creators → Spreaders → Enablers → Helpers → Users; **Users paling banyak**.
- **Telekomunikasi = tulang punggung**.
- 3 manfaat TIK sektor publik: efisiensi, kebijakan, transparansi.
