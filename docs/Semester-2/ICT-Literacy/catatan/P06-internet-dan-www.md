# P06 — Internet dan World Wide Web

Tanggal: 2026-11-25 · Sumber: `materi/Modul ICT Literacy_06_Internet dan World Wide Web.pdf`, `materi/Sesi 6 - Internet dan World Wide Web.pptx`, video "Video Sesi 6" (±7 menit)

## Ringkasan 3 kalimat
**Internet** adalah jaringan global yang menghubungkan perangkat dengan standar **TCP/IP**, sedangkan **WWW** adalah salah satu layanannya: halaman hypertext (HTML) yang diakses browser lewat **HTTP**. Sejarahnya berawal dari **ARPANET** (1960-an), TCP/IP (1982), NSFNET (1986), WWW oleh **Tim Berners-Lee di CERN (1989)**, hingga masuk Indonesia **1994**. Untuk memakainya perlu memahami browser, istilah web (link, download, upload, refresh), webmail, dan search engine.

## Konsep kunci

### 1. Internet vs WWW
**Intuisi**: internet = **jalan raya**; WWW = **salah satu kendaraan** yang lewat (email, FTP, VoIP juga lewat internet tapi bukan WWW).

| | Internet | WWW |
|-|----------|-----|
| Apa | jaringan fisik antar komputer | layanan halaman web ber-hyperlink |
| Protokol | **TCP/IP** | **HTTP** (+ HTML) |
| Pencipta | ARPA (Dephan AS) | Tim Berners-Lee (CERN) |

Definisi ahli: Onno W. Purbo (media efisiensi komunikasi), O'Brien (jaringan yang berkembang pesat), Berners-Lee (**jaringan dari jaringan**), Sarwono (tidak dimiliki satu pihak). *Internetworking* = proses menghubungkan jaringan. Media: kabel telepon, fiber optic, satelit, wireless.

### 2. Sejarah
| Tahun | Peristiwa |
|-------|-----------|
| 1960-an | **ARPANET** oleh ARPA (Dephan AS) |
| **1982** | TCP/IP dipublikasikan |
| 1986 | NSFNET menggantikan peran ARPANET untuk riset |
| **1989** | **Tim Berners-Lee** (CERN, Swiss) menciptakan WWW |
| 1990 | ARPANET dihentikan; CERN memperkenalkan WWW |
| 1993 | InterNIC untuk pendaftaran domain |
| **1994** | internet masuk Indonesia |

### 3. WWW
Sistem informasi (teks, gambar, suara, video) dalam format **hypertext/HTML**, diakses browser via **HTTP**. W3C: "semesta informasi yang dapat diakses jaringan".

### 4. Wi-Fi vs hotspot
- **Wi-Fi** = teknologi jaringan tanpa kabel.
- **Hotspot** = **tempat** sinyal Wi-Fi bisa ditangkap.

### 5. Browser & istilah web
Browser: Chrome, Firefox, Internet Explorer, Opera. Antarmuka: tab, **address bar (URL)**, back/forward/refresh.

| Istilah | Arti |
|---------|------|
| Link | teks/gambar yang bisa diklik ke halaman lain |
| Download | ambil file **dari** internet |
| Upload | kirim file **ke** internet |
| Back / Forward | halaman sebelumnya / berikutnya |
| Refresh | muat ulang halaman |
| Loading / Stop | proses membuka / menghentikan |

### 6. Webmail & search engine
- **Webmail**: email lewat browser (Gmail, Yahoo! Mail, Hotmail, AOL).
- **Search engine**: menelusuri konten WWW berdasarkan **kata kunci**; mengembalikan **daftar halaman**, bukan jawaban langsung (Google, Bing, Yahoo!).

## Istilah penting
| Istilah | Arti |
|---------|------|
| TCP/IP | protokol dasar internet |
| HTTP | protokol transfer halaman web |
| HTML | bahasa markup halaman web |
| URL | alamat halaman web |
| ARPANET | cikal bakal internet |
| CERN | lembaga riset Eropa tempat WWW lahir |

## Sering keluar di ujian / mudah keliru
- Internet ≠ WWW.
- **1989** WWW diciptakan; **1990** diperkenalkan; **1994** internet masuk Indonesia.
- Wi-Fi = teknologi, hotspot = tempat.
- Download = dari internet; upload = ke internet.
